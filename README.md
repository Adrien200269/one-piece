# ☠️ Grand Line Chronicles • One Piece Ultimate Anime Hub

[![React](https://img.shields.io/badge/React-19-61dafb.svg?logo=react&logoColor=black)](https://react.dev/)
[![Vite](https://img.shields.io/badge/Vite-8.3-646CFF.svg?logo=vite&logoColor=white)](https://vite.dev/)
[![Tailwind CSS](https://img.shields.io/badge/Tailwind_CSS-v4-38B2AC.svg?logo=tailwind-css&logoColor=white)](https://tailwindcss.com/)
[![One Piece](https://img.shields.io/badge/Anime-One_Piece-dc2626.svg)](https://one-piece.com/)

A modern, immersive One Piece anime website built with **React**, **Vite**, and **Tailwind CSS**, designed with an authentic Grand Line pirate parchment aesthetic.

---

## 🌟 Key Features

- **📜 Marine Bounty Archives & Lore Wiki**: 20+ prominent character dossiers (Gol D. Roger, Whitebeard, Shanks, Kaido, Luffy, Zoro, Law, Buggy, Garp) featuring authentic weathered Wanted posters, Conqueror’s Haki & Awakening tags, combat power ratings, and signature moves.
- **🍇 Devil Fruit Encyclopedia**: Deep dive into Paramecia, Logia, and Mythical Zoan classes with Awakening conditions (Sun God Nika, K-ROOM, Magma Cataclysms), risk tiers, and category filters.
- **🗺️ 11 Sagas & Canon Guide**: Interactive voyage map from *Romance Dawn* to *Egghead Island* with canon vs. filler breakdowns and an interactive checklist tracking your Grand Line Voyage percentage.
- **📜 Custom Wanted Poster Maker**: Full HTML5 Canvas forge allowing you to customize your name, epithet, berry bounty (up to ฿5.56B), upload custom photos, and download high-resolution PNG posters.
- **🎬 Grand Line Cinema & Soundboard**: Embedded high-definition Toei climax trailers and live Web Audio API sound synthesizers (Conqueror's Haki pulses, cannon blasts, ship bells, and treasure fanfares).
- **⚔️ Tavern Interactive Minigames**:
  - *Devil Fruit Awakening Personality Quiz* (with confetti celebrations)
  - *5-Billion Berry Dream Crew Builder* (draft a 5-member armada within budget)
  - *Higher / Lower Bounty Showdown* (bounty trivia streak challenge)
- **📡 Den Den Mushi Live Wire**: Real-time integration with the public MyAnimeList / Jikan v4 REST API for live anime stats, broadcast status, and character searches.

---

## 🛠️ Tech Stack

- **Framework**: React 19
- **Build Tool**: Vite 8
- **Styling**: Tailwind CSS v4 (@tailwindcss/vite)
- **Icons**: Lucide React
- **Audio**: Web Audio API (Synthesized in-browser sound effects)
- **Visuals & Effects**: Canvas Confetti, HTML5 Canvas Poster Renderer
- **Data**: Curated local One Piece encyclopedias + MyAnimeList / Jikan v4 REST API

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or newer)
- npm or yarn

### Installation

```bash
git clone https://github.com/Adrien200269/one-piece.git
cd one-piece
npm install
```

### Development Server

```bash
npm run dev
```

### Production Build

```bash
npm run build
npm run preview
```
